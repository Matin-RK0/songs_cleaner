# Roboto font assets

Roboto is an **open-source alternative**, not SamsungOne and not a claim to
reproduce the exact font in a particular Samsung Music/One UI configuration.

Official sources:
- https://fonts.google.com/specimen/Roboto
- https://github.com/google/fonts/tree/main/ofl/roboto
- https://raw.githubusercontent.com/google/fonts/main/ofl/roboto/OFL.txt

These unmodified TrueType files were obtained from Google Fonts' static-weight
CSS response on 2026-11-15 (normal style, normal width):

`https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;600;700;800&display=swap`

Resource base: `https://fonts.gstatic.com/s/roboto/v51/`

The SIL Open Font License and copyright notice are preserved in `OFL.txt`,
bundled with the application, and registered with Flutter's license registry.
No runtime font download is used. Vazirmatn remains an explicit fallback for
Persian/Arabic glyphs absent from Roboto.
